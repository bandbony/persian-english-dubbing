# دوبله‌ی ویدئوی فارسی به انگلیسی

یک وب‌اپ ساده: ویدئوی فارسی رو بارگذاری می‌کنی، متن و ترجمه‌ی انگلیسی رو بازبینی و ویرایش می‌کنی، و ویدئوی دوبله‌شده با صدای انگلیسی (در صورت امکان با صدای کلون‌شده‌ی خود گوینده)، زیرنویس انگلیسی و در صورت تمایل لب‌خوانی تحویل می‌گیری.

A small web app that dubs Persian videos into English: upload, review and edit the transcript and translation, then download the dubbed video with English subtitles and optional lip sync.

## مراحل

| مرحله | ابزار | فایل |
|---|---|---|
| ۱. استخراج صدا و جدا کردن گفتار از موسیقی | ffmpeg + Demucs | `app/pipeline/audio.py` |
| ۲. گفتار فارسی به متن با زمان‌بندی | Whisper (API اوپن‌ای‌آی) یا whisperX محلی | `app/pipeline/transcribe.py` |
| ۳. ترجمه با توجه به کل متن و طول هر جمله | Claude | `app/pipeline/translate.py` |
| — بازبینی و ویرایش متن و ترجمه در صفحه‌ی وب | | `app/templates/job.html` |
| ۴. ساخت صدای انگلیسی با صدای کلون‌شده‌ی گوینده | ElevenLabs | `app/pipeline/tts.py` |
| ۵. جا دادن هر جمله در زمان اصلی، میکس با موسیقی، زیرنویس | ffmpeg | `app/pipeline/align.py`, `output.py` |
| ۶. لب‌خوانی (اختیاری برای هر ویدئو) | sync.so | `app/pipeline/lipsync.py` |

همزمان‌سازی: هر جمله‌ی انگلیسی اول از زمان خودش و سکوت بعدش استفاده می‌کنه. اگه باز هم بلندتر باشه، تا `MAX_SPEEDUP` (پیش‌فرض ۱.۳۵ برابر) سریع‌تر پخش میشه بدون تغییر زیر و بمی صدا. اگه از این هم بلندتر باشه، جمله‌ی بعدی کمی دیرتر شروع میشه و این تأخیر در اولین مکث گفتار جبران میشه. Claude هم موقع ترجمه برای هر جمله یه سقف تعداد حروف (حدود ۱۵ حرف در ثانیه) می‌گیره، و صفحه‌ی بازبینی جمله‌های خیلی بلند رو قرمز نشون میده.

## راه‌اندازی

پیش‌نیاز: Python 3.11 یا جدیدتر و ffmpeg.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # کلیدهای API رو وارد کن
uvicorn app.main:app --reload
```

بعد http://localhost:8000 رو باز کن.

با Docker:

```bash
docker build -t dubbing .
docker run -p 8000:8000 --env-file .env -v "$PWD/data:/data" dubbing
```

### کلیدها و تنظیمات

همه‌ی تنظیمات از متغیرهای محیطی یا فایل `.env` خونده میشن؛ فهرست کامل در `.env.example` هست.

| متغیر | برای چی |
|---|---|
| `ANTHROPIC_API_KEY` | ترجمه |
| `OPENAI_API_KEY` | تبدیل گفتار به متن |
| `ELEVENLABS_API_KEY` | صدای انگلیسی و کلون صدا |
| `SYNC_API_KEY` و `PUBLIC_BASE_URL` | فقط برای لب‌خوانی |
| `APP_PASSWORD` | رمز صفحه‌ی وب؛ اگه اپ از اینترنت در دسترسه حتماً بذار |

**لب‌خوانی:** sync.so ویدئو و صدا رو خودش از اپ دانلود می‌کنه، پس اپ باید از اینترنت در دسترس باشه (سرور، یا تونل مثل cloudflared یا ngrok) و آدرسش در `PUBLIC_BASE_URL` باشه. برای کم کردن هزینه، فقط بخش‌هایی از ویدئو که توشون حرف زده میشه به sync.so فرستاده میشن (مکث‌های کوتاه‌تر از ۲ ثانیه جزو همون بخش حساب میشن) و بقیه‌ی ویدئو دست‌نخورده می‌مونه. صفحه‌ی بازبینی قبل از شروع، تخمین مدت لب‌خوانی رو نشون میده. مدل پیش‌فرض `lipsync-2` هست (ارزون‌ترین)؛ با `SYNC_MODEL=sync-3` کیفیت بهتر ولی حدود ۲.۵ برابر گرون‌تره.

## محدودیت‌های نسخه‌ی اول

- **یک گوینده:** صدای همه‌ی جمله‌ها از روی دو دقیقه‌ی اول گفتار کلون میشه. برای ویدئوهای چندگوینده باید تشخیص گوینده (pyannote) و یک صدای جدا برای هر نفر اضافه بشه.
- **طول ویدئو:** API ویسپر فایل تا ۲۵ مگابایت قبول می‌کنه، یعنی حدود ۵۰ دقیقه گفتار. پلن‌های sync.so هم سقف طول ویدئو دارن (Creator تا ۵ دقیقه).
- **Demucs** روی CPU کنده (برای یه ویدئوی ۱۰ دقیقه‌ای چند دقیقه). با `SEPARATOR=none` حذف میشه، ولی اون‌وقت موسیقی پس‌زمینه در خروجی نیست.
- صف کارها داخل خود برنامه است و یکی‌یکی پردازش میشن؛ برای چند کاربر همزمان باید یه صف واقعی (مثلاً Redis) اضافه بشه.
- فایل‌های هر کار در `data/jobs/<id>/` می‌مونن و خودکار پاک نمیشن.

## تست

```bash
pip install -r requirements-dev.txt
pytest
```

تست‌ها کل مسیر بارگذاری، بازبینی، دوبله و دانلود رو روی یه ویدئوی ساختگی اجرا می‌کنن، با سرویس‌های پولی جایگزین‌شده؛ پس به کلید API نیاز ندارن.
